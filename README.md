# Memory Card Web Game 🧠🃏

An elegant, highly interactive web-based **Memory Card Game** engineered using clean, modern frontend technologies. This project showcases dynamic DOM manipulation, robust game-state tracking, asynchronous card-matching algorithms, and smooth CSS3 3D transforms.

---

## 🚀 Key Features

* **Asynchronous Match Evaluator:** Implements an optimized Javascript state-machine that captures user clicks, locks the viewport during evaluation, and checks for card matches with precise timing.
* **3D Card Flip Animations:** Utilizes modern CSS3 properties (`perspective`, `transform-style: preserve-3d`, and `backface-visibility`) to deliver smooth, visually satisfying 3D flipping effects.
* **Algorithmic Shuffle Pipeline:** Features an instant card scrambling mechanism (using optimized array shuffling methods) to ensure a unique layout configuration upon every runtime session.
* **Responsive Grid Layout:** Built with a clean, fluid grid system that scales seamlessly across modern desktops, tablets, and mobile devices.
* **Persistent Performance:** Designed with zero external dependencies (Vanilla JS/CSS), ensuring blazing-fast rendering and an immediate load footprint.

---

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling & Animation:** CSS3 (Flexbox/Grid, 3D Transforms, Custom Transitions)
* **Logic & State Engine:** Vanilla JavaScript (ES6+)
